For grown-ups

This game connects familiar picture names to English capital letters. Say “apple” together, then repeat the first sound slowly before looking for A. Each visit offers a new set of words from A to Z.

Try it together, away from the screen

Start with three familiar items, such as a cup, a ball and a book. Name each item together. Ask which two begin alike, then write B beside the ball and book. If your child is unsure, say the words for them and try one more time together.

For X, the game uses “xylophone.” Its first sound in English is usually like Z, even though it starts with the written letter X.
